## rust-systems-practice
Hands-on Rusts System programming excercises, written with raw libc calls
 
  - mycat: cat with open/read/write/close, partial writes, EINTR 
  - mywc: wc with chunk-boundary word counting
  - mini-shell: fork/exec/wait, cd, exit, exit status, multi-stage pipe support, output redirection, input redirection and Ctrl+C
